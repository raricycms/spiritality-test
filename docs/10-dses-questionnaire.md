# 10 DSES 日常灵性体验模块

本模块是自评问卷，与三个能力实验独立展示、存储和计分，不进入机会命中率或异常能力概率。

## 来源与版本

- 原版问卷：[作者官网 PDF](https://www.dsescale.org/DSES.pdf)，已按用户要求下载到 `public/dses/DSES-original-en.pdf`，保留原文及版权说明。
- 下载日期：2026-10-10；文件 74,218 字节；SHA-256：`62AF1FD5F36EC6D71812942FD008426C5948F47DF62D039AA34D54589D47A181`。
- 计分采用[作者 2022 年 1 月更新说明](https://www.dsescale.org/scoring-of-the-daily-spiritual-experience-scale/)，不能误用早期的反向计分。
- 官网[翻译说明](https://www.dsescale.org/translations/)提及已验证中文版本，但本次没有取得可核验的中文问卷文件。用户选择英文原版与中文辅助理解；中文界面、答题说明和逐题主题摘要不标称正式译本或经验证中文版。

## 页面与计分

中文操作界面提供原版 PDF 阅读／打开入口，以及按原版题号对应的 16 项答题卡。完整英文原题以原始 PDF 为准，逐题中文主题摘要仅辅助理解，不把摘要当作替代问卷。

- 第 1–15 题：从未 1、偶尔 2、有些日子 3、大多数日子 4、每天 5、每天多次 6。
- 第 16 题：完全不亲近 1、有些亲近 3、很亲近 5、尽可能亲近 6。
- 主要结果：已答题目分值总和除以已答题数；全答时分母为 16。允许缺失时须显示已答数、缺失数，不把空答案当作 0 分；零答不计算或保存结果。
- 记录计分版本 `underwood-2022`、原题语言、中文辅助说明标识、16 项答案及完成时间，便于个人纵向比较。
- 不设通用“高／中／低灵性”门槛，不推断超自然能力，不构造未经验证的分量表。

独立 localStorage key：`spirituality:v2:dses`；与实验历史分别导入导出，保留 v1 记录。问卷能在实验服务端暂时不可用时独立填写；答题状态和记录不上传服务端。

## 子代理边界与必要验证

DSES Claude Code 子代理仅拥有新 `src/lib/dses.js`、`src/components/DsesQuestionnaire.jsx`、对应 CSS 和 `src/lib/__tests__/dses.test.js`。主代理在其他前端工作完成后接入 App，避免同时修改同一文件。

只验证计分方向、第 16 题特殊映射、缺失与非法答案、独立存储／导出，以及入口贯通。现有原版 PDF 的下载真实性通过文件头及摘要校验记录。
